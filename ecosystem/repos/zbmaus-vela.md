# zbmaus-vela

**Visibilitas:** Publik · **Branch:** `main` · **Push terakhir:** 18 Nov 2026 · **Ukuran:** ~31 KB

## Peran
Blueprint infrastruktur VPS zbmaus: instruksi instalasi, skrip deployment OS/VPS, unit systemd, dan panduan operasional mentah. Tanpa kredensial.

## Isi Pokok
- `install.sh` — skrip instalasi awal
- `docs/` — BOTS, CONFIG, INSTALL-PROMPT, SECURITY-BACKUP, TROUBLESHOOTING
- `examples/` — contoh konfigurasi
- `services/` — definisi service
- `systemd/` — unit timer/service

## Catatan
Sumber prosedur instalasi. Rahasia, env, dan state runtime tidak berada di sini (lihat `zbmaus-vela-secrets`, privat).
